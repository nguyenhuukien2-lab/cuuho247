# Admin V1 bundle

`admin-v1.0.0-production.zip` contains only the contents of `admin_web/dist`.
The bundle was built in production mode with the audited Supabase URL and
public publishable key. It contains no environment file or backend source.

Admin's private npm package metadata remains `0.0.0`; the release package is V1.
Existing lint and chunk-size advisories are recorded in the release report.
This bundle has not been deployed. The last recorded production preflight
still requires reconciliation migration alignment and authenticated checks.
