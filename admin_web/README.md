# Cứu Hộ 24/7 Admin Web

Giao diện mô phỏng trung tâm điều hành cứu hộ xe, xây dựng bằng React, Vite, TypeScript, Tailwind CSS, React Router, Lucide và Recharts. Toàn bộ nội dung nghiệp vụ sử dụng dữ liệu mẫu trong 'src/mocks/mockData.ts'; chưa kết nối Supabase hoặc API thật.

## Chạy cục bộ

- npm install
- npm run dev
- npm run build
- npm run lint

Mở địa chỉ Vite in ra trong terminal. Trang '/' là tổng quan; '/login' là màn hình đăng nhập mô phỏng. Đăng nhập demo chỉ chuyển hướng về dashboard, không xác thực tài khoản.

## Các trang

Tổng quan, yêu cầu cứu hộ và chi tiết, khách hàng và hồ sơ, đối tác và hồ sơ, dịch vụ, báo giá và doanh thu, đánh giá, bản đồ vận hành, thông báo, cài đặt.

Các thao tác điều phối, duyệt, phát thông báo và lưu cấu hình chỉ cập nhật giao diện tại phiên hiện tại hoặc hiển thị xác nhận demo.
